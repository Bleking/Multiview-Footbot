# Multiview-Footbot
축구 입문자를 위한 다중 시점 기반 경기 장면 설명 서비스

# 프로젝트 문제정의
축구 입문자는 경기 중 판정과 선수 움직임을 보더라도 ‘왜 그런 상황이 발생했는지’, ‘어느 부분을 봐야 하는지’를 스스로 이해하기 어렵다. 기존 검색이나 용어 설명은 실제 경기 장면과 분리되어 있어, 눈앞의 장면을 이해하는 데 한계가 있다.

# 프로젝트 목적
경기 영상에서 관찰 가능한 시각적 증거와 축구 규칙·전술 지식을 연결해, 축구 입문자가 특정 경기 장면의 의미와 이유를 이해하도록 돕는다.

# 궁극적 사용자 가치
축구를 잘 몰라도 경기의 맥락을 이해하며 즐길 수 있도록 관람 진입장벽을 낮춘다.

# 확장된 산업적 가치
리그·구단·방송사·축구 콘텐츠 플랫폼의 신규 팬 온보딩 및 경기 이해 콘텐츠 제작을 지원할 수 있다.

# 기술 문제
- 한 개의 시점만으로는 정보가 불완전한 video understanding 문제에서 여러 시점의 evidence를 어떻게 결합하고, 외부 규칙 지식을 grounding하여 신뢰 가능한 설명을 생성할 것인가?

- 영상 이해 : VLM이 축구 장면에서 이해해야 할 요소들
   - 누가 무엇을 했는지
   - 어디에서 접촉했는지
   - 어떤 시점에서 중요한 사건이 발생했는지
- 규칙 Grounding ㅣ 영상에서 관찰한 내용을 설명할 때 연결해야할 것들
   - IFAB 규칙
   - 공식 심판 지침
   - 공식 Q&A

- 결론: Video Understanding + Knowledge Grounding + Explanation

# VLM (필수, MUST)
## 역할 : 무슨일이 일어났는가
- 선수 위치 (누가 어디에 있는지)
- 공 위치 (공이 언제 전달됐는지)
- 접촉 여부 (어떤 접촉이 발생했는지)
- 접촉 위치
- 선수 행동 (선수 움직임이 어떤지)
- 장면의 핵심 사건
- 서로 다른 시점에서 무엇이 추가로 보이는지

# RAG (MUST)
IFAB Law 12 중심

## 역할 : 일어난 일에 대한 답변을 어떤 규칙·개념으로 생성할지 외부 지식에 근거해서 도울 기술; 외부 규칙 grounding
- 특정 장면과 관련된 공식 규칙 -> 규칙 정확성 (근거 제시)
- 공식 근거 제공
   - 파울 판단 기준
   - 카드 적용 기준
   - 전술 개념
   - 전술 개념 보완
   - 관찰 사실과 규칙 해석 연결
- 규칙 오류 감소
- 출처 제공
- 규정 변경 대응

## RAG가 개선할 수 있는 요소들
- 규칙 정확성
- 설명 일관성
- 출처 제시
- 환각 억제
- 규칙 변경 대응
- 입문자 친화적 설명
